# clashctl 交互式控制面板

## 概述

`clashctl` 新增了交互式控制面板模式。运行 `clashctl`（不带任何参数）即可进入一个带实时状态面板的交互式主菜单，通过输入数字选择功能，操作完成后自动回到菜单。无需记忆任何子命令。

```bash
# 进入交互式控制面板
clashctl

# 原有的命令行用法完全不变
clashctl on
clashctl sub add https://example.com
clashon
```

## 主菜单

运行 `clashctl` 后进入主菜单界面：

```
╔═══════════════════════════════════════════════════╗
║              clashctl 控制面板                      ║
╠═══════════════════════════════════════════════════╣
║  内核: mihomo    状态: [ON]                        ║
║  订阅: [1] https://example.com/subscription...     ║
║  Tun:  [OFF]     系统代理: [ON]                    ║
║  端口: mixed=7890  http=  socks=                   ║
╚═══════════════════════════════════════════════════╝

  [1] 🔌 开启代理         [2] 🔌 关闭代理
  [3] 📡 订阅管理         [4] 🔧 Tun 模式
  [5] 🌐 系统代理         [6] 🔑 Web 密钥
  [7] 🖥️  Web 控制台       [8] 📋 查看日志
  [9] ⬆️  升级内核         [10] ⚙️  Mixin 配置
  [0] 🚪 退出

  请选择 [0-10]:
```

### 状态面板说明

| 字段 | 说明 |
|------|------|
| 内核 | 当前使用的代理内核名称（mihomo / clash） |
| 状态 | `[ON]`（绿色）= 内核运行中；`[OFF]`（红色）= 已停止 |
| 订阅 | 当前使用的订阅 ID 和 URL（超长自动截断） |
| Tun | Tun 模式开关状态 |
| 系统代理 | 系统代理环境变量是否生效 |
| 端口 | mixed-port、HTTP port、SOCKS port 的当前值 |

### 主菜单操作

| 选项 | 功能 | 说明 |
|------|------|------|
| `1` | 开启代理 | 启动内核 + 设置系统代理环境变量 |
| `2` | 关闭代理 | 停止内核 + 清除系统代理环境变量 |
| `3` | 订阅管理 | 进入订阅管理子菜单 |
| `4` | Tun 模式 | 进入 Tun 模式子菜单 |
| `5` | 系统代理 | 进入系统代理子菜单 |
| `6` | Web 密钥 | 输入新密钥修改，留空查看当前密钥 |
| `7` | Web 控制台 | 显示内网/公网/公共控制台地址 |
| `8` | 查看日志 | 显示最近 30 行内核日志 |
| `9` | 升级内核 | 请求内核自动升级 |
| `10` | Mixin 配置 | 进入 Mixin 配置子菜单 |
| `0` | 退出 | 退出控制面板，返回原始终端 |

## Tun 模式子菜单

```

║              Tun 模式                               ║
╠═══════════════════════════════════════════════════╣

╚═══════════════════════════════════════════════════╝

  [1] 🔛 开启 Tun         [2] 🔻 关闭 Tun
  [0] ⬅️  返回主菜单
```

| 选项 | 功能 | 说明 |
|------|------|------|
| `1` | 开启 Tun | 以 sudo 权限启动内核，启用 TUN 设备路由所有流量 |
| `2` | 关闭 Tun | 关闭 TUN 模式，恢复普通代理模式 |

> **注意：** Tun 模式需要 root 权限。开启时会自动 sudo 重启内核，关闭时同样需要 sudo。

## 交互细节

### 信号处理

- **Ctrl+C**：在菜单选择和暂停等待时被忽略，不会退出控制面板。用户只能通过输入 `0` 正常退出。
- **子进程**：菜单中执行的命令（如 `clashlog | tail -30`）仍可被 Ctrl+C 中断，因为 SIGINT 由终端驱动发送到前台进程组。

### 错误处理

控制面板运行期间，`_error_quit` 被临时替换为仅打印错误信息并 `return 1`（而非原始的 `exec $SHELL -i`）。这确保了：
- 操作失败时显示红色错误信息
- 错误后自动回到菜单，不会意外退出终端
- 退出控制面板后自动恢复 `_error_quit` 的原始行为

### 状态刷新

每次操作完成后（按回车继续），菜单会重新渲染，状态面板实时反映最新的内核运行状态、订阅信息、Tun 状态和端口配置。

## 向后兼容

所有原有的命令行用法完全不受影响：

```bash
# 命令行直接操作（不进入菜单）
clashctl on              # 开启代理
clashctl off             # 关闭代理
clashctl status          # 查看状态
clashctl sub add <url>   # 添加订阅
clashctl tun on          # 开启 Tun
clashctl mixin -e        # 编辑 Mixin
clashctl upgrade -v      # 升级内核（带日志）

# 快捷别名（不进入菜单）
clashon
clashoff
clashui
clashtun on
clashsub ls

# 仅以下方式进入交互式控制面板
clashctl                 # 无参数 → 交互菜单
```

## 技术实现

### 文件变更

| 文件 | 变更类型 | 说明 |
|------|----------|------|
| `scripts/cmd/common.sh` | 新增函数 | `_menu_box`、`_menu_box_end`、`_menu_row`、`_read_choice`、`_pause` |
| `scripts/cmd/clashctl.sh` | 新增函数 | `_menu_status`、`_menu_main`、`_menu_sub`、`_menu_tun`、`_menu_proxy`、`_menu_mixin` 及对应的 `*_items` 函数 |
| `scripts/cmd/clashctl.sh` | 修改函数 | `clashctl()` 的空参数分支改为调用 `_menu_main` |
| `scripts/cmd/clashctl.fish` | 修改函数 | `clashctl` 无参数时桥接到 bash 进入菜单 |

### 架构设计

```
clashctl (无参数)
  └─ _menu_main()           ← 主菜单循环
       ├─ _menu_status()    ← 状态面板（调用 yq 读取配置）
       ├─ clashon / clashoff 直接复用现有函数
       ├─ _menu_sub()       ← 订阅子菜单循环
       │    └─ _sub_add / _sub_del / _sub_use / _sub_update / _sub_list / _sub_log
       ├─ _menu_tun()       ← Tun 子菜单循环
       │    └─ clashtun on / clashtun off
       ├─ _menu_proxy()     ← 系统代理子菜单循环
       │    └─ clashproxy on / clashproxy off / clashproxy
       ├─ _menu_mixin()     ← Mixin 子菜单循环
       │    └─ clashmixin / clashmixin -e / clashmixin -c / clashmixin -r
       └─ clashui / clashlog / clashupgrade / clashsecret 直接复用
```

### 设计原则

1. **零新依赖**：纯 Bash 内置命令实现，不依赖 dialog、whiptail、fzf 等外部工具
2. **复用优先**：菜单仅负责 UI 和分发，所有业务逻辑完全复用现有函数
3. **中英文对齐**：`_menu_box` 和 `_menu_row` 通过逐字符检测（`[^\x00-\x7F]`）计算终端显示宽度，中文字符按 2 列宽计算，保证边框对齐
4. **ANSI 颜色保留**：`_menu_row` 使用 `printf '%b'` 输出，支持在文本中嵌入 ANSI 转义码（如状态面板的绿色 `[ON]` / 红色 `[OFF]`）
